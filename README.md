## Recommended private-repo submodule

```bash
git submodule add https://github.com/leavesnight/ProjectEternal-Web.git Web
git commit -m "Add public website submodule"
```

Do not place private game source, unreleased assets, credentials, API keys, or confidential content in this public repository.

Update the privacy policy before releasing features such as multiplayer, accounts, analytics, crash reporting, cloud saves, voice, or community features.
