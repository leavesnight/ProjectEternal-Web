Project Eternal 隐私政策

更新日期：2026 年 8 月 12 日 · 适用版本：v0.1.0

当前 v0.1.0 为单机体验版本，不要求注册账号，不含广告，不含应用内购买，也不提供开发者自建的在线账号或联机服务。

一、我们处理的信息

当前版本不会通过 Project Eternal 主动收集、上传或存储可用于直接识别用户身份的个人信息。游戏可能在本地设备保存设置、运行状态或存档数据，用于维持游戏功能。

二、设备权限与 XR 功能

作为 XR/VR 游戏，Project Eternal 使用头显与控制器提供的姿态、方向和输入信息，实现视角、移动、交互及机甲操控。当前版本不使用麦克风、相机拍摄、通讯录或精确地理位置权限来收集个人信息。

三、第三方平台与基础服务

Project Eternal 基于 Unity 与 OpenXR 开发，并可运行于 PICO 等兼容平台。应用分发、安装、设备系统服务、平台账号及平台级日志等，可能由相应平台依据其自身隐私政策处理。

四、数据存储与传输

当前版本由我们主动处理的游戏数据主要保存在用户本地设备。我们目前不运营用于 v0.1.0 的游戏账号服务器、广告服务器、分析服务器或云存档服务器。

五、未成年人保护

Project Eternal 不以收集未成年人个人信息为目的。未成年人应在监护人指导下使用本应用及 XR 设备。

六、未来功能变更

后续版本可能增加匿名房间联机、云存档、账号、错误报告或其他在线能力。如这些功能涉及新的数据处理行为，我们会在相应版本发布前更新本隐私政策。

七、安全与更新

我们会采取与项目规模相匹配的合理安全措施，并可能根据产品功能、平台规则或法律法规变化更新本政策。
